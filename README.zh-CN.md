# 孩子提醒（Kid Reminder）

面向孩子的每日清单应用。家长通过网页后台管理任务；孩子在原生 macOS 应用里查看清单并勾选完成。

**语言：[English](README.md) | 中文**

## 架构

```
┌─────────────────────────── Mac Mini（家庭局域网内）──────────────────────────┐
│  Node.js 后端（端口 2021）                                                     │
│   ├── REST API   → GET /api/tasks, POST /api/tasks/:id/toggle, …              │
│   ├── SQLite     → kidreminder.db（任务 + 每日完成记录）                        │
│   └── 管理后台   → 单个 HTML 页面（家长，需 PIN）                               │
└────────────────────────────────────────────────────────────────────────────────┘
        ▲ HTTP（局域网）                                  ▲ HTTP（局域网，浏览器）
        │                                                   │
┌───────┴───────────────────┐            ┌─────────────────┴──────────────┐
│  孩子的 macOS 应用         │            │  家长的浏览器 / 手机            │
│  （SwiftUI，清单 +         │            │  http://<mac-mini-ip>:2021    │
│   早间提醒）               │            │  （添加 / 编辑 / 删除任务）     │
└───────────────────────────┘            └────────────────────────────────┘
```

## 后端（已部署）

零依赖 Node.js —— 仅使用内置的 `node:http` + `node:sqlite`。

```bash
cd backend
node server.js        # PORT=2021, ADMIN_PIN=1234（可通过环境变量覆盖）
```

| 接口 | 认证 | 说明 |
|---|---|---|
| `GET /api/tasks?date=YYYY-MM-DD&type=todo\|countdown` | — | 查询某天的任务（默认今天）。`type=todo`= 仅每日清单；`type=countdown`= 仅未来事件。返回 `{ today, date, type, tasks: [...] }` |
| `POST /api/tasks` | `X-Admin-Pin` 或 `X-Kid-Pin` | 创建任务 `{ title, emoji, repeat, targetDate?, countdownEnabled?, countdownStart? }`；记录创建者 `createdBy` |
| `PATCH /api/tasks/:id` | `X-Admin-Pin` | 编辑任务（仅管理员） |
| `DELETE /api/tasks/:id` | `X-Admin-Pin` 或 `X-Kid-Pin` | 删除；管理员可删任意任务，孩子只能删自己创建的任务 |
| `POST /api/tasks/:id/toggle` | — | 标记完成 / 取消完成；`{ minutes }` = 花费时间，存入当天的完成记录 |
| `POST /api/verify` | — | 校验 PIN |
| `GET /`, `/admin` | — | 家长管理后台 |

重复类型：`daily`（每天）、`weekly`（每周）、`biweekly`（每两周）、`monthly`（每月）、`once`（一次）。

倒计时：`targetDate`（YYYY-MM-DD）是任务的日期；`countdownEnabled` 开启倒计时；
`countdownStart`（默认 7）是倒计时开始显示的剩余天数阈值。`daysLeft` 由服务器根据请求的 `date` 计算。

### 行为规则

- **重复** —— `daily` 每天显示；带日期的非倒计时 `once` 任务只在其日期当天显示；
  无日期的 `once` 完成后隐藏；倒计时 `once` 事件在完成前一直可见（供倒计时面板倒计时）；
  `weekly`、`biweekly`、`monthly` 只在计划日显示（以任务日期为锚点，未设日期则以创建日为准）。
- **顺延** —— 每日任务当天未完成会自动出现在第二天。
- **任意日期** —— `?date=` 可查看某一天的视图：历史日期显示当天完成情况（含 `minutes`），未来日期显示计划。
- **权限** —— **管理员 PIN** 拥有全部权限；**孩子 PIN**（`KID_PIN`）界面相同，但孩子只能**编辑或删除自己创建的任务**。
  家长创建的任务对孩子锁定（不显示编辑/删除按钮，服务器也会返回 403）。两个角色都可以添加任务和标记完成。
- **仅家长可见的任务** 🔒 —— 添加/编辑任务时，家长可勾选 **🔒 仅家长可见**。此类任务**对孩子完全隐藏**
  （服务器会从所有列表中过滤掉，孩子尝试勾选/编辑/删除都会收到 403）。家长端会显示 🔒 徽标，并保留
  对家长任务和孩子任务的完整操作权限（勾选、编辑、删除）。
- **宝可梦收藏** ⚡ —— 当孩子完成**当天全部**任务后，家长可以颁发一枚 **⭐ 印章**（日历上显示金色标记）。
  孩子每完成一个任务都会播放**欢快的提示音** 🎵。在 **⚡ 宝可梦** 面板中，孩子可以**花 1 枚印章随机解锁一只宝可梦**
  —— 先收集**关都（151 只）**，集齐后**城都（100 只）**会自动作为第二代解锁。未解锁的位置显示 **?**。
  每次解锁都会播放**胜利音效**并展示宝可梦；点击已解锁的宝可梦会**弹出大图**显示详细信息（名字、属性）。
  精灵图与音效由后端 `/sprites/`、`/sounds/` 提供 —— 非商业用途，私人家庭使用公共 PokéAPI 精灵图。

## 管理后台功能

- **日历** —— 月视图，显示每日完成圆点（全部完成绿色 / 部分完成橙色）和**倒计时事件日期的粉色标记**；点击任意日期查看。
- **表情选择** —— 下拉框选择表情，无需手动输入。
- **记录时间** —— 标记完成时输入花费分钟数，显示为 `⏱ Nm`。
- **红色高亮** —— 未完成的一次性（`once`）任务以红色显示。
- **两个面板** —— **📋 今天** 页签为每日清单（含日历）；未来日期任务在单独的 **⏳ 倒计时** 页签。
- **添加任务弹窗** —— 点击 **＋** 弹出表单：名称、表情、**重复** 下拉框（每天 / 每周 / 每两周 / 每月 / 一次）、**日期** 字段、**倒计时** 复选框（勾选后可设置提前天数）。
- **孩子模式** —— 孩子看到与家长**完全相同的界面**（完整日历、今天/倒计时页签、添加、时间、倒计时）。唯一区别：孩子只能编辑/删除自己创建的任务（家长任务不显示 ✏️/🗑 按钮，服务器同样返回 403）。
- **倒计时** —— 为未来任务（如考试）设置目标日期。在 `countdownStart` 窗口内显示实时 `⏳ Nd` 倒计时，当天显示 `📅 Today!`，过期显示 `⏰ Nd ago`。未来事件在到期当天之前无法勾选完成。
- **导航** —— 宽屏下页签在左侧竖排 sidebar；窄屏（手机）下退回顶部，自动换行排列，不会挤成一排。

## 中文听写

一个生字词库（生字、词语、拼音、例句——按识读/识写和年级分类）驱动自适应听写练习：

- **薄弱优先** —— 每次听写从孩子答错最多的字（`correct_count` 最低）里抽 10 个词，打乱顺序。
- **只放语音，不显示文字** —— 孩子听到词语+例句朗读（语音合成见下文）后写下来，测验过程中屏幕上不显示任何文字。
- **家长批改** —— 孩子做完后，这次记录进入"待批改"状态，家长在网页后台逐词标 ✓/✗，批改结果会更新这个字的薄弱/掌握计数，影响下次抽题。
- **网页后台** —— `📚 生词库` 页签（词库完整增删改查）和 `📝 听写记录` 页签（历史记录：已批改/待批改/放弃的进行中记录，带删除按钮清理）。

## 英语错题练习

一个错题库（`english_questions`），内容来自孩子真实的错题——填空/拼写、选择题、句子转换三种题型，每条都带正确答案和简短解析。

- **自动批改** —— 孩子输入/选择的答案会自动跟正确答案比对（支持多个都算对的答案），不需要家长批改这一步。跟听写一样，采用薄弱优先的自适应抽题。
- **拼写朗读** —— 被标记为拼写类的填空题会有一个 🔊 按钮，朗读填对后的完整句子。
- **自我纠错** —— 句子转换题如果被自动批改误判过严，孩子可以在看到正确答案后翻一次判定结果。
- **网页后台** —— `📖 英语错题` 页签（题库增删改查）和 `📋 英语练习记录` 页签（只读的练习历史，因为批改是自动完成的）。
- **macOS 应用** —— 可以直接做题，也可以通过 **➕ 添加一道错题** 表单把新错题录进同一个题库（跟网页后台管理的是同一张表）。
- **自动保持同步** —— 孩子把错题记在一个私有 GitHub 仓库里；Mac mini 上每周会自动拉取一次，把新增的条目导入进来（幂等，重复跑也不会出问题）。详见
  [`tools/english-wrong-answers/README.md`](tools/english-wrong-answers/README.md)。

### 语音合成

听写和拼写朗读都由一个私有的神经网络语音合成服务（Qwen3-TTS）生成，跟后端一起跑在同一台机器上，每个词/题只合成一次，缓存到磁盘。如果这个服务繁忙或不可用，后端会自动退回使用 macOS 自带的 `say` 语音——音质差一些，但总能立刻用，🔊 按钮不会彻底哑掉。

## macOS 应用

原生 SwiftUI 应用（`macos-app/`）。**今天**清单、**日历**（月视图，含完成圆点 + 粉色倒计时事件标记，点击任意日期查看）、**倒计时**面板、**听写**和**英语错题**页签，以及**设置**（配置服务器 IP、端口、PIN，修改立即生效，无需重启）。构建会生成带自定义图标的已签名 `.app`（图标来自 `Resources/AppIcon.svg`）。

### 下载应用

从 **Releases** 页面获取最新版本：
<https://github.com/Yihong89/kid-reminder/releases>

`KidReminder.zip` 为**通用构建**（Apple Silicon 和 Intel 都可用）。解压后把
`KidReminder.app` 拖入「应用程序」，打开 **设置** 填入服务器 IP、端口和 PIN。

因为应用是**临时签名**（未公证），macOS 门禁（Gatekeeper）会阻止首次启动。
任选一种方式放行一次：

- 右键点击 `KidReminder.app` → **打开** → 再点 **打开**
- 或者：系统设置 → 隐私与安全性 → 向下滚动 → 点击 Kid Reminder 旁的 **仍要打开**
- 或者在终端执行：`xattr -d com.apple.quarantine /path/to/KidReminder.app`

**自动更新：** 应用启动时会检查 GitHub 上的新版本；在 **设置 → 更新** 中点击 **下载并更新**，
即可自动下载、替换并重启为新版本（无需手动下载）。

### 从源码构建（无需 Xcode，只需命令行工具 + Swift）

```bash
cd macos-app
./build.sh        # 生成 build/KidReminder.app
```

把 `KidReminder.app` 拷贝到 MacBook，首次启动时**右键 → 打开**。
首次运行打开 **设置**，填入服务器 IP、端口和 PIN。孩子 PIN 解锁清单（只能操作自己的任务）；
管理员 PIN 拥有全部权限。应用在每次请求时读取连接设置，因此修改立即生效。

## 操作审计日志

所有会改数据的 `/api` 请求都会记进 `audit_log` 表，这样「这几个 stamp 是谁发的、
从哪台设备发的」事后查得到。读请求不记（量大，也不是关心的问题）；`/api/verify`
也不记 —— 它是唯一一个把 PIN 放在请求 **body** 里的接口，记了就等于把 PIN 明文写进
数据库。表里只存请求**认证成的角色**，永远不存 PIN 本身。

被拒绝的请求同样会记录（`role='none'`、`status=401`），所以试密码也会留下痕迹。

```bash
# 最近的操作（时间是 UTC，本地时间 = UTC+8）
sqlite3 -header -column ~/kidreminder/kidreminder.db \
  "SELECT datetime(at,'+8 hours') AS local, role, ip, method, path, status, detail
     FROM audit_log ORDER BY id DESC LIMIT 30;"

# 只看 stamp / 宝可梦相关 —— 谁发的、谁花的
sqlite3 -header -column ~/kidreminder/kidreminder.db \
  "SELECT datetime(at,'+8 hours') AS local, role, ip, path, status, detail
     FROM audit_log WHERE path LIKE '%stamps%' OR path LIKE '%unlock%' ORDER BY id;"

# 认证失败的尝试
sqlite3 -header -column ~/kidreminder/kidreminder.db \
  "SELECT datetime(at,'+8 hours') AS local, ip, method, path FROM audit_log WHERE status = 401;"
```

## 部署说明

- 服务器通过 launchd 自启动（`com.kidreminder.server`）。
- 仅局域网使用；建议在路由器上为 Mac Mini 设置 DHCP 保留地址，保持 IP 稳定。
- 完整部署指南：[backend-setup.md](backend-setup.md)
- 部署方式：`scp backend/server.js robot@<mini>:~/kidreminder/server.js`，然后
  `launchctl kickstart -k gui/$(id -u)/com.kidreminder.server`。新表由启动时的
  `CREATE TABLE IF NOT EXISTS` 自动建好，不需要单独的迁移步骤。
