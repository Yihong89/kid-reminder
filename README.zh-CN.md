# 孩子提醒（Kid Reminder）

面向孩子的每日清单应用。家长通过网页后台管理任务；孩子在原生 macOS 应用里查看清单并勾选完成。

**语言：[English](README.md) | 中文**

## 架构

```
┌─────────────────────────── Mac Mini（家庭局域网内）──────────────────────────┐
│  Node.js 后端（端口 2021）                                                     │
│   ├── REST API   → GET /api/tasks, POST /api/tasks/:id/toggle, …              │
│   ├── SQLite     → kidreminder.db（任务 + 每日完成记录）                        │
│   └── 管理后台   → 单个 HTML 页面（家长，需 PIN）                               │
└────────────────────────────────────────────────────────────────────────────────┘
        ▲ HTTP（局域网）                                  ▲ HTTP（局域网，浏览器）
        │                                                   │
┌───────┴───────────────────┐            ┌─────────────────┴──────────────┐
│  孩子的 macOS 应用         │            │  家长的浏览器 / 手机            │
│  （SwiftUI，清单 +         │            │  http://<mac-mini-ip>:2021    │
│   早间提醒）               │            │  （添加 / 编辑 / 删除任务）     │
└───────────────────────────┘            └────────────────────────────────┘
```

## 后端（已部署）

零依赖 Node.js —— 仅使用内置的 `node:http` + `node:sqlite`。

```bash
cd backend
node server.js        # PORT=2021, ADMIN_PIN=1234（可通过环境变量覆盖）
```

| 接口 | 认证 | 说明 |
|---|---|---|
| `GET /api/tasks?date=YYYY-MM-DD&type=todo\|countdown` | — | 查询某天的任务（默认今天）。`type=todo`= 仅每日清单；`type=countdown`= 仅未来事件。返回 `{ today, date, type, tasks: [...] }` |
| `POST /api/tasks` | `X-Admin-Pin` 或 `X-Kid-Pin` | 创建任务 `{ title, emoji, repeat, targetDate?, countdownEnabled?, countdownStart? }`；记录创建者 `createdBy` |
| `PATCH /api/tasks/:id` | `X-Admin-Pin` | 编辑任务（仅管理员） |
| `DELETE /api/tasks/:id` | `X-Admin-Pin` 或 `X-Kid-Pin` | 删除；管理员可删任意任务，孩子只能删自己创建的任务 |
| `POST /api/tasks/:id/toggle` | — | 标记完成 / 取消完成；`{ minutes }` = 花费时间，存入当天的完成记录 |
| `POST /api/verify` | — | 校验 PIN |
| `GET /`, `/admin` | — | 家长管理后台 |

重复类型：`daily`（每天）、`weekly`（每周）、`biweekly`（每两周）、`monthly`（每月）、`once`（一次）。

倒计时：`targetDate`（YYYY-MM-DD）是任务的日期；`countdownEnabled` 开启倒计时；
`countdownStart`（默认 7）是倒计时开始显示的剩余天数阈值。`daysLeft` 由服务器根据请求的 `date` 计算。

### 行为规则

- **重复** —— `daily` 每天显示；带日期的非倒计时 `once` 任务只在其日期当天显示；
  无日期的 `once` 完成后隐藏；倒计时 `once` 事件在完成前一直可见（供倒计时面板倒计时）；
  `weekly`、`biweekly`、`monthly` 只在计划日显示（以任务日期为锚点，未设日期则以创建日为准）。
- **顺延** —— 每日任务当天未完成会自动出现在第二天。
- **任意日期** —— `?date=` 可查看某一天的视图：历史日期显示当天完成情况（含 `minutes`），未来日期显示计划。
- **权限** —— **管理员 PIN** 拥有全部权限；**孩子 PIN**（`KID_PIN`）界面相同，但孩子只能**编辑或删除自己创建的任务**。
  家长创建的任务对孩子锁定（不显示编辑/删除按钮，服务器也会返回 403）。两个角色都可以添加任务和标记完成。

## 管理后台功能

- **日历** —— 月视图，显示每日完成圆点（全部完成绿色 / 部分完成橙色）和**倒计时事件日期的粉色标记**；点击任意日期查看。
- **表情选择** —— 下拉框选择表情，无需手动输入。
- **记录时间** —— 标记完成时输入花费分钟数，显示为 `⏱ Nm`。
- **红色高亮** —— 未完成的一次性（`once`）任务以红色显示。
- **两个面板** —— **📋 今天** 页签为每日清单（含日历）；未来日期任务在单独的 **⏳ 倒计时** 页签。
- **添加任务弹窗** —— 点击 **＋** 弹出表单：名称、表情、**重复** 下拉框（每天 / 每周 / 每两周 / 每月 / 一次）、**日期** 字段、**倒计时** 复选框（勾选后可设置提前天数）。
- **孩子模式** —— 孩子看到与家长**完全相同的界面**（完整日历、今天/倒计时页签、添加、时间、倒计时）。唯一区别：孩子只能编辑/删除自己创建的任务（家长任务不显示 ✏️/🗑 按钮，服务器同样返回 403）。
- **倒计时** —— 为未来任务（如考试）设置目标日期。在 `countdownStart` 窗口内显示实时 `⏳ Nd` 倒计时，当天显示 `📅 Today!`，过期显示 `⏰ Nd ago`。未来事件在到期当天之前无法勾选完成。

## macOS 应用

原生 SwiftUI 应用（`macos-app/`）。**今天**清单、**日历**（月视图，含完成圆点 + 粉色倒计时事件标记，点击任意日期查看）、**倒计时**面板，以及**设置**（配置服务器 IP、端口、PIN，修改立即生效，无需重启）。构建会生成带自定义图标的已签名 `.app`（图标来自 `Resources/AppIcon.svg`）。

### 下载应用

从 **Releases** 页面获取最新版本：
<https://github.com/Yihong89/kid-reminder/releases>

`KidReminder.zip` 为**通用构建**（Apple Silicon 和 Intel 都可用）。解压后把
`KidReminder.app` 拖入「应用程序」，打开 **设置** 填入服务器 IP、端口和 PIN。

因为应用是**临时签名**（未公证），macOS 门禁（Gatekeeper）会阻止首次启动。
任选一种方式放行一次：

- 右键点击 `KidReminder.app` → **打开** → 再点 **打开**
- 或者：系统设置 → 隐私与安全性 → 向下滚动 → 点击 Kid Reminder 旁的 **仍要打开**
- 或者在终端执行：`xattr -d com.apple.quarantine /path/to/KidReminder.app`

**自动更新：** 应用启动时会检查 GitHub 上的新版本；在 **设置 → 更新** 中点击 **下载并更新**，
即可自动下载、替换并重启为新版本（无需手动下载）。

### 从源码构建（无需 Xcode，只需命令行工具 + Swift）

```bash
cd macos-app
./build.sh        # 生成 build/KidReminder.app
```

把 `KidReminder.app` 拷贝到 MacBook，首次启动时**右键 → 打开**。
首次运行打开 **设置**，填入服务器 IP、端口和 PIN。孩子 PIN 解锁清单（只能操作自己的任务）；
管理员 PIN 拥有全部权限。应用在每次请求时读取连接设置，因此修改立即生效。

## 部署说明

- 服务器通过 launchd 自启动（`com.kidreminder.server`）。
- 仅局域网使用；建议在路由器上为 Mac Mini 设置 DHCP 保留地址，保持 IP 稳定。
- 完整部署指南：[backend-setup.md](backend-setup.md)

## 功能规划（计划中）

接下来想实现的功能：

1. **成就 / 贴纸系统** 🏅
   - 孩子完成当天所有任务后，家长可以给孩子盖一枚**印章**。
   - 印章会显示在**日历**上（每天一个标记）。
   - 集齐足够印章后**升级**，并在应用界面**解锁宝可梦贴纸**。

2. **多孩子支持** 👨‍👧‍👦
   - 一个家长账号可以关联**多个孩子账号**。
   - 家长可以**分别管理每个孩子的任务**，并单独给每个孩子盖章。

3. **仅家长可见的任务** 🔒
   - 部分任务**只有家长能看到和管理**，孩子看不到。
